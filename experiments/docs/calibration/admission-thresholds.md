# 表格候选准入阈值校准报告

本文保留既有阈值选择证据；目录迁移后重新计算了覆盖率与派生图，未改变人工标签或生效阈值。现有数据位置及维护规则见 [标签说明](admission-labels.md)。

## 1. 结论

本阶段统一使用以下双向覆盖率阈值：

```text
MIN_CANDIDATE_COVERAGE = 0.65
MIN_SLOT_COVERAGE = 0.77
```

候选只有在两个覆盖率同时达到阈值时才准入。阈值适用于全部工具和策略，不设置来源特判。

## 2. 校准数据

- 文档：4 份实验 PDF；
- 人工标注：109 个 candidate，其中 `admit` 56 个、`reject` 53 个；
- 可与同页 Docling Table Slot 比较：95 个，其中 `admit` 56 个、`reject` 39 个；
- 无同页 slot：14 个，均为人工 `reject`，由 `no_eligible_table_slot_on_page` 直接拒绝，不参与覆盖率阈值校准。

人工标签及逐候选覆盖率见 [人工标签](../../data/calibration/admission-labels.md)，候选的二维分布可在[交互式双向覆盖率图](../../output/calibration/admission-coverage-chart.html)中查看。

## 3. 校准方法

对可比较样本枚举所有能够改变分类结果的候选阈值与卡位阈值组合，并按以下顺序选择：

1. 首先最小化 `FP`，避免非表格或不完整候选进入 grouping 和 scoring；
2. 在 `FP` 相同的组合中最小化 `FN`，尽量保留完整候选；
3. 若多个阈值组合产生相同分类结果，不把阈值贴在某个样本值上，而从保持结果不变的稳定区间中部取便于配置的数值，降低轻微 bbox 波动造成分类翻转的风险；
4. 用逐候选错误清单复核统计结果，确认错误符合业务取舍，而不是数据或标注错误。

这里的目标不是追求当前小样本上的最高 F1，而是先满足“精确率优先”的准入职责。准入遗漏时仍有 Docling 原生 TableItem 保底；错误准入则可能让非表格内容进入后续选优和回填，因此 FP 的代价更高。

## 4. 关键矛盾

当前样本不能被“两个覆盖率同时达到阈值”的规则完全分开：

| 人工标签 | candidate_id | candidate_coverage | slot_coverage |
|---|---|---:|---:|
| admit | camelot_stream_p01_t01 | 0.791302 | 0.717766 |
| reject | unstructured_hi_res_p02_t02 | 1.000000 | 0.723789 |

要让第一个候选通过，`MIN_SLOT_COVERAGE` 必须不高于 `0.717766`；但这样第二个候选也会通过。要拒绝第二个候选，slot 阈值必须高于 `0.723789`，因此必然同时拒绝第一个候选。candidate 阈值无法解决该冲突，因为 reject 样本的 candidate coverage 为 `1.0`。

因此只能二选一：

- 降低 slot 阈值：得到至少 1 个 FP；
- 提高 slot 阈值：保住 `FP=0`，接受至少 1 个 FN。

本流程选择后者，因为准入阶段以精确率优先。

## 5. 稳定区间与最终取值

在保持 `FP=0、FN=1` 的前提下，当前样本允许的联合阈值区间为：

```text
0.588718 < MIN_CANDIDATE_COVERAGE <= 0.717735
0.723789 < MIN_SLOT_COVERAGE <= 0.809951
```

区间边界分别来自最接近决策面的 reject 与 admit 样本。最终取 `0.65` 和 `0.77`，接近各自稳定区间中部，并保留两侧边界裕量。这样比直接取某个准入样本的最低覆盖率更稳健：后者会把阈值贴在样本边界上，而且仍无法解决上述正负样本交叉冲突。

## 6. 当前效果

仅统计 95 个可比较样本：

- `TP`（真正例）：人工标注为 `admit`，且覆盖率阈值判断为准入；
- `FP`（假正例）：人工标注为 `reject`，但覆盖率阈值错误地将其准入；
- `FN`（假负例）：人工标注为 `admit`，但覆盖率阈值错误地将其拒绝；
- `TN`（真负例）：人工标注为 `reject`，且覆盖率阈值判断为拒绝。

| TP | FP | FN | TN | Precision | Recall | F1 |
|---:|---:|---:|---:|---:|---:|---:|
| 55 | 0 | 1 | 39 | 1.000000 | 0.982143 | 0.990991 |

唯一 FN 是 `ORDER PERU 24-12 ANDET.pdf` 的 `camelot_stream_p01_t01`。它仍不会导致表格内容丢失：同一 slot 中还有其他正确准入候选，并且最终流程保留 Docling 原生 TableItem 作为兜底。

与暂定阈值 `0.75 / 0.80` 相比，新阈值在维持 `FP=0` 的同时，将 FN 从 3 个降为 1 个。

## 7. 适用范围与重新校准

该结论只由当前四份业务 PDF 支持，不代表对所有 PDF 分布都已充分验证。出现以下任一情况时，应补充人工标签并重新执行同样的校准流程：

- 加入新的文档类型、版式或语言；
- 更换 Docling、其他提取工具或关键解析配置；
- 修改公共坐标转换、Table Slot 或 candidate bbox 生成逻辑；
- 线上发现新的误准入或误拒绝模式；
- 新样本使当前稳定区间明显收窄或消失。

重新校准时应更新本报告，不得根据单个异常样本直接增加工具特判。


## 文档归属

本报告保存校准证据，执行规则以 [需求规格](../requirements.md) 为准。以上统计来自既有四份样本，不是本轮新跑的独立验证结果。`admission-calibration` 命令复算标签覆盖率并生成交互图，不自动修改 selection_config，也不等价于自动执行本报告的完整阈值搜索。
