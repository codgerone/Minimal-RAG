V3.13 对比：LLM 结构标注、引导句、表格摘要

7 种入库方式 × 返回命中 chunk（C）/ 整表（T），共 13 种组合（摘要只有 T）；混合检索，K=3，512 token；LLM 为 google/gemini-3.8-flash。代号：RM 规则 Markdown，RL 规则表头映射，LM / LL LLM 结构标注 + Markdown / 表头映射，“+”加引导句，S 摘要。

结论

  • 结论 排除 3 个与表格入库无关的证据组后（见第二个视图的说明），返回整表时：S-T 每道表格题平均需要 1.67 个返回单元，12 道表格题全部在前 3 个单元内覆盖表格证据；LM+-T 1.83（11 / 12）；RM-T 2.08、RL-T 2.33（都是 10 / 12）。未排除时同样是 S-T、LM+-T、LL+-T 最好（3.33–3.50，11 / 12），RM-T、RL-T 3.58、3.67。
  • 结论 支配判定：排除后保留 RM-T（零成本）、LM+-T（$0.025）、S-T（$0.045）三种；未排除时保留 RM-T、LM+-T，S-T 以 0.17 个单元之差被 LM+-T 支配。差距都只来自 1–3 道题，每种 LLM 方式只跑了一次。
  • 结论 返回单元：每种入库方式都是返回整表（T）优于只返回命中 chunk（C）。C 模式下 PO-25-19-Q001、Q003 无论哪种入库方式都要 8 个单元：ELCTO、ENSA 的数据分布在数量表的多个 chunk 里（roadmap C6），只有返回整表能一次带回。
  • 结论 引导句：LM-T → LM+-T 平均所需单元数 2.17 → 1.83，LL-T → LL+-T 2.42 → 2.00（排除后）。变好的是 PO-25-19 的单价（单价表 chunk 名次 10 → 8，所需单元数 4 → 2）、PO-24-12-Q004（3 → 2）。另一面，排第 1 的表格证据组由 26 组减为 24 组：CONTRACT-105-Q002 的几张同类合同表都加了引导句后，最好的一块由第 1 降到第 2（原因未做对照实验）。
  • 问题 LLM 结构标注本身（不加引导句）没有带来收益：排除后 LM-T 2.17 对 RM-T 2.08、LL-T 2.42 对 RL-T 2.33。12 张表的标注全部正确，但只有 PO 25-19 数量表有分节，其余表 LLM 判出的表头与规则相同，能改变切法的只有这一张表。
  • 结论 摘要：表格 chunk 名次最好（排除后平均 1.19，32 组中 32 组进前 3），所需单元数也最少；代价是入库花费 $0.045，约为结构标注的 1.8 倍，且只能返回整表（没有 C 模式）。
  • 结论 写法：只返回命中 chunk 时 Markdown 明显优于表头映射（排除后 RM-C 3.00 对 RL-C 4.42），返回整表时差别很小（2.08 对 2.33，整表文本相同，差别只来自排名）。
  • 结论 护栏（全部 24 题，K=3）：完整覆盖 RL-T、LL-T、LM+-T、LL+-T、S-T 都是 20 题，RM-T、LM-T 18 题；RL-T 与 V3.12 相同（命中 22、完整覆盖 20），整表改存 Markdown 后每题平均返回 token 1,860 → 1,259。

指标怎么读

  • 表格证据组、表格题：词坐标全部落在解析器给出的表格框内的 excerpt 为表格 excerpt（30 段）；含表格 excerpt 的证据组为表格证据组（35 组），含表格证据组的题为表格题（12 题）。
  • 指标 1 表格 chunk 名次（每个表格证据组）：全量 chunk 排名中（换成整表之前），覆盖该组表格 excerpt 任一词的 chunk 里最靠前者的名次。只看“最容易找到的一块”。
  • 指标 2 表格证据所需返回单元数（每道表格题）：在全量返回单元排名中，覆盖该题全部表格证据（只算表格 excerpt）需要前几个单元；题内取各表格证据组的最大值。K=3 时只看前 3 个单元，所以“≤ 3”的题就是默认设置下表格证据能完整返回的题。
  • 指标 3 表格证据所需 token（每道表格题）：上述前“指标 2”个返回单元的 token 之和。
  • 所需单元下限（每道表格题）：与排名无关，覆盖表格证据至少要几个返回单元（整表算一个）。
  • 平均与中位数：平均反映整体水平，但会被个别很差的题拉高（如 CONTRACT-105-Q003 需要约 20 个单元）；中位数不受个别题影响；“≤ 3 的题”回答“默认设置下能完整返回几题”。三者一起看。

支配判定

目的：13 种组合在效果、返回 token、入库成本上各有长短。这一节先筛掉“有另一个组合在三方面都不比它差、至少一方面更好”的组合——选它没有任何理由；剩下的组合之间才需要按取舍来选。

比较范围：每个组合都与其余 12 个组合逐一比较，所有组合的比较范围相同。

三个维度（都越小越好）：表格证据 = 指标 2 的平均（每道表格题覆盖其表格证据所需的返回单元数）；返回 token = 指标 3 的平均（每道表格题覆盖其表格证据所需的 token）；入库成本 = 一次入库 12 张表的 LLM 花费。

判定：若组合 B 在三个维度上都不比 A 大、且至少一个维度更小，则 A 被 B 支配。“判定”列列出支配 A 的全部组合；一个都没有就保留。

局限：只比数值大小，不考虑差异是否超出随机扰动（平均所需单元数差零点几、只因一两道题）；也不看护栏（K=3 的完整覆盖等）。所以“被支配”只说明在这三个维度上不占优，取舍仍要结合逐题对照。
