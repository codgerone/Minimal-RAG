## 本轮重点

- V3.0 是唯一运行实现；旧版名称只用于历史证据，旧 `--pipeline` 命令参数不保留。
- 解析只交付完整语义文档，分块独立；所有文档都经过必接组装器。
- 连接、接入规则、数量与插件配置分离；同一接口统一契约，不以版本区分公共模型。
- Docling 单次转换共享、表格评分的 PDF 原文依赖、表头与文本化责任、审核失败阻断发布均显式纳入设计。
- 检索、问答、评估、索引健康、发布与恢复都纳入接口体系，不只处理正常入库路径。
