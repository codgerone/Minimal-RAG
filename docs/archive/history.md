## 检索效果基线

数据集：5 份 PDF、24 道问题（`eval/ground-truth/`），K=3，证据映射为人工审核。

### 实验：bge-m3 稀疏检索（数据集 3.2.0，未采用）

| 装配 / 检索器 | 命中率 | 证据组召回 | 完整覆盖 | Chunk 精确率 | MRR | 跨文档污染 |
|---|---:|---:|---:|---:|---:|---:|
| `plain_text` BM25 | 12.50% | 11.11% | 8.33% | 26.39% | 35.42% | 0.00% |
| `plain_text` bge-m3 sparse | 16.67% | 13.19% | 12.50% | 22.22% | 37.50% | 0.00% |
| `plain_text` bge-m3 sparse（查询去编码） | 16.67% | 15.28% | 12.50% | 25.00% | 34.72% | 0.00% |
| `plain_text` 向量 + BM25（默认） | 50.00% | 40.28% | 33.33% | 51.39% | 80.56% | 0.00% |
| `plain_text` 向量 + bge-m3 sparse | 20.83% | 17.36% | 16.67% | 29.17% | 51.39% | 0.00% |
| `plain_text` 向量 + bge-m3 sparse（查询去编码） | 45.83% | 34.72% | 29.17% | 47.22% | 75.69% | 0.00% |
| `structured` BM25 | 37.50% | 34.03% | 29.17% | 33.33% | 43.75% | 0.00% |
| `structured` bge-m3 sparse | 41.67% | 36.11% | 29.17% | 22.22% | 34.03% | 0.00% |
| `structured` bge-m3 sparse（查询去编码） | 45.83% | 42.36% | 37.50% | 33.33% | 50.00% | 0.00% |
| `structured` 向量 + BM25（默认） | 87.50% | 82.64% | 79.17% | 48.61% | 86.81% | 0.00% |
| `structured` 向量 + bge-m3 sparse | 70.83% | 63.19% | 54.17% | 31.94% | 55.56% | 0.00% |
| `structured` 向量 + bge-m3 sparse（查询去编码） | 83.33% | 78.47% | 75.00% | 44.44% | 88.89% | 0.00% |

K=3，文档过滤开启，索引与 V3.9 相同（不重建）。纯向量见 V3.9 一节；本实验中纯向量、BM25、向量 + BM25 的结果与 V3.9 基线逐项一致。

做法：稀疏权重按 FlagEmbedding 的 BGEM3 计算——最后一层隐状态经 `sparse_linear.pt` 线性层与 ReLU 得到每个 token 的权重，同一 token 取最大值，去掉特殊 token；chunk 得分 = 问题与 chunk 共有 token 的权重乘积之和，范围内得分大于 0 的 chunk 参与排名。融合与 `hybrid` 相同（RRF，k = 60）。"查询去编码"为对照组：只在稀疏一路的问题中删去标识表登记的编码，检索范围仍按编码确定。

结论：

1. **bge-m3 稀疏权重只落在输入中出现的 token 上，不做词项扩展**。中文问题的 token 在西、英文 chunk 中没有匹配，跨语言匹配仍完全依赖向量检索。
2. **原样使用时，标识编码的子词碎片主导稀疏排名**：分词器把 `ORDER2025001`、`CONT2025001` 切成 `▁OR`、`DER`、`2025`、`001` 等，匹配标题中的 ORDER 与所有含 2025 年日期的 chunk。structured 24 题中，稀疏第 1 名有 10 题的最大贡献 token 为 `2025`。BM25 把编码当作一个词，库中不出现，不受影响。融合后把这些噪声带进 Top-3，向量 + sparse 低于纯向量。
3. **去掉编码后，稀疏与 BM25 持平**：structured 较 BM25 变好 3 题、变差 2 题。变好的 3 题共有 token 只剩权重约为 0 的空白 token，属于偶然；变差的 2 题，一题因分词区分大小写（问题 `Mora`、正文 `mora`）未匹配，一题因稀疏权重与库内词频无关，多个含 `fiel cumplimiento` 的 chunk 分不出先后。
4. **融合时不如现行混合检索**：向量 + sparse（查询去编码）较向量 + BM25，structured 变好 0 题、变差 2 题，plain_text 变好 1 题、变差 2 题。

不加入系统。复现：`.venv/Scripts/python.exe reports/experiments/v3.9-bge-m3-sparse/run_experiment.py`（不改动系统代码，运行时替换评估所用的检索器，结果写在同一目录）；逐题对比页为该目录下的 `compare/lexical/`、`compare/fused/`。
