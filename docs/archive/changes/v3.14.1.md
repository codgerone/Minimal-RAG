### 1. 文档语言的文本由哪次调用写

**事实**：V3.14 的问题语言改写、step-back 由写法调用 v8 写出（与译文、HyDE 同一次调用），对比页的 240 种配置都依据这些文本。

**选项**：
- A：另加一次调用，只写文档语言的改写与 step-back；问题语言的文本沿用 v8。V3.14 已有的配置与数据不变，新结果直接并入。两种语言的文本来自不同调用，规则文字除语言外相同。
- B：新调用同时写两种语言，三种用法都取自同一次调用。更公平，但问题语言的改写、step-back 会有两份（v8 一份、新调用一份），对比页上要区分。

**推荐 A**。不同调用带来的差别属于"重新生成一次"的扰动，4 次独立生成已能显示它的大小。

### 2. 评估哪些配置

**事实**：V3.14 评估了 240 种配置（检索文本 20 种状态 × 去编码 2 × 分解 6 种状态）。改写、step-back 各加 3 种语言后，若全部组合都评估，检索文本有 72 种状态，共 864 种配置，数据约为现在的 3.6 倍（现有 `data.json` 约 20 MB、逐配置文件约 13 MB，都在 git 中）。

**选项**：
- A：全部 864 种；
- B：只加与决策 015 结果表对应的三种用法，每种用于改写、step-back 各两种新语言（文档语言、两种）：单独（代替原句）、与原句融合、叠加在"原句 + 译文"上。共 12 种新的检索文本状态，× 去编码 2 × 分解 6 = 144 种，合计 384 种。其余组合在配置框中选出时显示"未评估"（现有提示）。

**推荐 B**。V3.15 中兜底方式单独返回，真正要用的是"单独"；融合、叠加与决策 015 的表格对齐，便于对照。

## 目标

比较改写、step-back 三种语言用法的检索效果，供 V3.15 选定一种：
- 问题语言（V3.14 现状）；
- 文档语言：检索范围内每种文档语言一段；
- 两种：问题语言与文档语言的各段各检索一次后 RRF 融合。

## 改什么

**1. 文档语言写法调用**（新提示词 `query_plan_lang_v1`，只用于本实验与 V3.15）

- 输入：与写法调用相同的问题列表（不分解时为原问题，分解时为冻结规划的子问题）；文档语言由代码填入。
- 第 g 次生成的输入取第 g 次生成的规划（g = 0–3），缓存同样按生成编号隔离。
- 规模：32 道可回答题 × 2 种规划（不分解、分解）× 4 次生成 = 256 次调用。
- 校验：每个编号恰好一条；每种文本每种语言至多一段且非空。不合格时带检查项重试一次，仍不合格记为降级，该题的文档语言用法不可用，单独列出。
- 问题已是某种文档语言时，该语言跳过；此时"文档语言"用法中这种语言由问题语言的文本代替。

提示词全文（`{languages}` 由代码填入，与 v8 相同的部分逐字沿用）：

```
You write alternative phrasings of questions for document retrieval. You never answer the questions.

The documents searched are written in: {languages}.
The input is a list of questions, each with an id. For each question and for each of {languages} the question is not already written in, write the following phrasings in that language, each from the question itself (no phrasing is derived from another):
- rewrite: the question as a statement or noun phrase without question words and filler, in the terms documents in that language use; keep names, codes and numbers as written.
- step_back: a broader but still concrete question about the same documents, in the terms documents in that language use: drop the qualifiers that narrow the question to one instance (one entity, item or period) when the answer for every instance would be written in the same place; never ask for general knowledge or what such documents usually contain.

Answer with one entry per question, with its id.
```

与 v8 的差别：语言改为每种文档语言；加"用该语言文档的术语"（v8 翻译的要求）；改写的"引用的术语原样保留"改为"名称、编码、数字照写"（引用的术语要译成文档语言，沿用 v8 翻译的规则）。

**2. 检索**（规则写入 `rules/query-planning.md`）

- 改写、step-back 各有语言选项：问题语言、文档语言、两种。
- 不融合（代替原句）时，用这种写法的全部文本检索；多于一段时各检索一次后 RRF 融合。V3.14 中不融合的配置每题都恰好一段，结果不变。这条也是 V3.15 中"一种方式有几段文本时 RRF 融合"的规则。
- 融合时，选定语言的各段文本与其他文本一起参与 RRF。

**3. 查询侧对比页**（`reports/query/v3.14/`，原页更新）

- **配置框**：② 中改写、step-back 各加一行语言选项（问题语言 / 文档语言 / 两种），勾选该写法后可选，默认问题语言。示意：
