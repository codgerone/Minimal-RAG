# 跨页续表

> **规则摘要**
> - 阅读顺序中相邻、分处相邻两页的两张表，逐对判定后一张是否为前一张的续表。
> - 四个条件全部满足才算续表：
>   - **位置**：前表在页面末尾、后表在页面开头，两表之间的文字很少；
>   - **列几何**：列数相同，外沿与列分界对齐；
>   - **列类型**：两边都稳定的列，类型不冲突；
>   - **表头**：后表自己认不出表头。
> - 续表与前表合并成一张表，之后的表头判定、文本化、分块都按一张表处理，规则不变。续表可以连成链，整条链合并成一张。
> - 判定只使用前序环节交付的结果：主文档的阅读顺序和节点类型、Docling 的表格位置、各位置采用的表格。不重新读取 PDF。
> - 原始的选优结果和各页表格不改；续表判断单独记录，合并后的表由判断派生。

代码：`rag/ingest/tables/continuation.py`；在 `rag/ingest/tables/prepare.py` 中位于"采用表格"之后、"表头判定"之前。

## 1. 参与判定的表格对

- 在主文档的阅读顺序中，相邻的两个表格位置记为 A、B，中间可以有文字节点，但不能有其他表格。
- A 在第 N 页，B 在第 N+1 页。
- 两张表各自只在一页上：表格位置跨页时，Docling 不给页码，这样的表不参与判定。

## 2. 条件

### 2.1 位置

页高为表格位置所在页的高度。表格的上下边界取 Docling 识别的表格位置，与哪个工具胜出无关。

```
A 的位置 = A 的下边界 / 页高     ≥ 0.8
B 的位置 = B 的上边界 / 页高     ≤ 0.2
```

**两表之间的文字**：
- 范围：阅读顺序中 A、B 之间的文字节点和列表项，去掉 Docling 判为页眉（header）、页脚（footer）的节点。
- 按节点的页码分为第 N 页部分和第 N+1 页部分，两部分分别计算宽度。
- 宽度 = 每个非空白字符的宽度之和：Unicode 东亚宽度为 F 或 W 的字符计 2，其他字符计 1，空白不计。
- 两部分各自不超过 120。

页眉页脚只按 Docling 的判定去掉；被误判为正文的页眉计入宽度，由 120 的上限容纳。

### 2.2 列几何

两张表都用采用后的表格（选优胜者或 Docling 原生结构）。

- **列区间**：每列取有文字、只占一列的单元格，从它们左边界的最小值到右边界的最大值。没有这样的单元格的列，不算区间。
- **外沿**：一张表所有列区间的最左端到最右端。
- **外沿重叠** = 两表外沿的交集长度 / 并集长度。
- **列分界**：第 k 列与第 k+1 列都有区间时，取第 k 列区间的右端与第 k+1 列区间的左端，以两者中较小者为左、较大者为右，得到分界范围。画线工具给出的是一条线，按文字推出列的工具给出的是两列文字之间的空隙。
- **相对偏移**：对两表都有的分界 k，
  ```
  距离     = 两表在分界 k 的范围之间的距离（范围相交时为 0）
  相对偏移 = 距离 / 两表在分界 k 两侧共四个列区间中最窄者的宽度
  ```

**对齐**：以下各项同时满足。
1. 列数相同；
2. 外沿重叠 ≥ 0.8；
3. 每个可比分界的相对偏移 ≤ 0.35；
4. 可比分界数 × 2 ≥ 全部分界数（列数 − 1）。

任一张表没有任何列区间（单元格没有坐标）时，记为"无法判定"，不判为续表。任一张表的网格无效（表头判定的输入检查结论为网格无效）时，不判为续表。

### 2.3 列类型

沿用[表头判定](table-header.md)的类型词法、取样规则和稳定类型定义。

- **取样**：
  - A 从最后一行起向上取样，到表身第一行为止：A 认出表头时为表头以下，否则为全表；
  - B 从第一行起向下取样；
  - 两边各取至多 8 行，跳过的行与表头判定相同（汇总行、分节行、空白行等）。
- **稳定类型**：每列至少 2 个观察，所有观察的可能类型有共同的货币金额、其他数字或日期。
- **冲突**：同一列在两边都有稳定类型，且两者没有交集。有任何一列冲突，就不是续表。两边都稳定的列一个也没有时，这一条不否决。

### 2.4 后表的表头

B 单独做表头判定，结论为"已认出"时，不是续表。

## 3. 合并

- 一条续表链（B 续 A、C 续 B……按阅读顺序）合并成一张表，表格 ID 为各部分表格 ID 用 `+` 连接。
- 各部分的行按顺序接在前一部分之后，列按序号对齐；单元格的文字、坐标、跨度不变，只平移行号。
- 合并后的表记录每一部分的表格位置、表格 ID、页码和行范围。
  - chunk 的来源区域按单元格所在行的部分取页码；
  - chunk 来源的页码按所含行的部分取。
- 跨页处不合并单元格，纵向合并格不跨页延续。
- 合并后的表在链的第一个表格位置产出一个表格节点，其余位置不再产出节点。两表之间的文字节点留在阅读顺序中，排在合并后的表格之后。
- 合并后的表重新做表头判定；文本化与分块按一张表进行。

## 4. 参数

| 参数 | 值 | 依据 |
|---|---|---|
| 位置带 | 页面上下各 20% | 用户在 Word 中调试确定 |
| 两表之间文字宽度上限 | 每侧 120 | 用户确定；约为一到两行正文 |
| 外沿重叠下限 | 0.8 | 同一张物理表在不同工具间的实测最低值为 0.86 |
| 列分界相对偏移上限 | 0.35 | 同一张物理表在不同工具间的实测最高值为 0.28 |

列几何实验：`reports/experiments/v3.11-continuation/`（素材为全部候选表，按同一张物理表 / 不同的表分组）。

## 5. 已知限制

- 后表重复印了前表表头时，后表认出表头，不判为续表。
- 一行内容被分页切开（单元格文字跨页）时不拼接，两半各成一行。
- 前表若是跨页表格位置（Docling 不给页码），不参与判定。
- 合并后的表格记录第一部分的工具与策略；各部分的工具与策略见其表格 ID。
- 页面上下 20%、宽度 120、两个列几何阈值只在本库 5 份 PDF（1 个续表）上检查过，没有做校准。
