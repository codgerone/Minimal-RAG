# 扫描页 OCR

> **规则摘要**
> - 每份 PDF 逐页判定：有文字层、扫描页、空白页。只有扫描页 OCR，有文字层的页（包括扫描仪自带的 OCR 文字层）原样使用。
> - OCR 是解析之前独立的一步，只认字：每行、每词的文字、框与置信度。结果作为事实保存（`ocr.json`），各配置共用；OCR 设置不变时不重做。
> - 由原 PDF 与 OCR 事实派生一份带隐形文字层的 PDF（`ocr.pdf`）。下游凡是读 PDF 的环节（解析器、表格工具、证据读取、`anchors`、审核页截图）对含扫描页的文档都读它；标题、段落、表格等结构由现有解析流程从它恢复。
> - `ocr.pdf` 生成后自检：扫描页读回的词序列与 OCR 事实逐词相同、每个词框偏差 ≤ 1 点；不通过时该文档入库失败。
> - 引擎是可替换环节（`OcrEngine`），内置 `rapidocr`。路线的取舍见[决策 020](../decisions/020-ocr-route.md)，行方向规则见[决策 019](../decisions/019-line-orientation.md)。

代码：`rag/ingest/ocr/`（`pages.py` 页面判定，`recognize.py` 渲染、方向、纠偏，`rapidocr_engine.py` 引擎，`text_layer.py` 文字层 PDF 与自检，`step.py` 编排与事实文件）。

## 页面判定

| 判定 | 条件 | 处理 |
|---|---|---|
| 文字层 | PyMuPDF `get_text("text")` 去掉首尾空白后非空 | 原样使用 |
| 扫描页 | 文字为空，且页面上画有至少一张图片 | OCR |
| 空白页 | 文字为空，且没有图片 | 跳过 |

文档类型由页面判定得出：没有扫描页为数字 PDF；非空白页全部是扫描页为扫描 PDF；两者都有为部分扫描。判定结果写入每份索引的中间结果 `pages.json`。

配置了 `[ocr]` 时，含扫描页的 PDF 可以入库；没有配置时，扫描页不读，全部页面都没有文字层的 PDF 为"无法读取"。

## 识别一页

1. **渲染**：按 `[ocr] dpi`（内置 300）渲染为灰度图，页面的 `/Rotate` 在渲染时已应用。不取嵌入的原图，一页多图、图片缩放统一处理。
2. **方向**：先按原方向识别。有效字符（字母、数字）为 0，或竖向文字行（框高 > 框宽）超过一半时，再把图像顺时针转 90°、180°、270° 各识别一次，取"各行平均置信度 × 有效字符数"最大的方向；相同时取先试的方向。
3. **倾斜**：取上边长度大于左边长度 5 倍的文字行，按其四边形上边的角度取中位数；绝对值 ≥ 0.3° 时，把图像绕中心反向转回该角度（尺寸不变、白色填充）后重新识别，结果以重新识别的为准。
4. **行方向**：每次识别读两遍，引擎的行方向分类器开一遍、关一遍；两遍检测框相同，每个框保留置信度高的读法，相同时保留分类器关的读法。
5. **输出**：每行的文字、四边形框（像素）、置信度，以及引擎给出的逐词文字、框、置信度。

**坐标**：PDF 点 = 像素 × 72 / dpi，原点在页面左上角，与 `BoundingBox` 相同；纠偏后的坐标对应纠偏后的图像。下游的全部坐标都对应 `ocr.pdf` 的页面。

## 事实文件

`.rag/ocr/<原文件哈希前 16 位>-<OCR 设置哈希前 8 位>/ocr.json`。OCR 设置为 `[ocr] use`、`dpi` 与引擎身份（引擎名、版本、模型文件名、行方向规则）。按页记录判定、原页面的 `/Rotate`、渲染 dpi、各方向的试识别统计与选中的方向、倾斜角与是否纠偏、识别图像的尺寸，以及各行、各词的文字、框、置信度。OCR 设置另含 OCR 的规则版本与所用库的版本，整体进入 OCR 一步的构建记录。

## 文字层 PDF

- 有文字层的页从原 PDF 原样复制。
- 扫描页新建一页，按显示尺寸（方向转了 90° 或 270° 时宽高互换），把识别所用的图像（方向与纠偏都已应用）铺满整页，再按 OCR 词框写入隐形文字（`render_mode = 3`），每个词后跟一个空格。
- 字号使字体的上伸部到下伸部等于框高，再水平缩放使该词宽度等于框宽。字体为 PyMuPDF 内置 CJK 字体（覆盖拉丁字母与中文），每页只登记一份字体资源。
- 文档的 `file_hash` 仍是原文件的哈希（增量入库、标注绑定不变）；`ocr.pdf` 另有哈希。

**自检**：PyMuPDF 按内容流顺序从 `ocr.pdf` 每个扫描页读出的词序列与 OCR 事实逐词相同，每个词框与 OCR 词框四边的偏差都 ≤ 1 点；页数与原文件相同。

## 审核

入库审核页的"OCR"标签页（只在文档含扫描页时出现）列出每页的判定、方向、倾斜角，在扫描页图像上叠加 OCR 词框，并按行列出识别文字；置信度 < 0.8 的词标为红色，每页另计低置信度词数。

不做：手写、印章、签名的识别，图片内容理解，OCR 后的文字纠错；低置信度的词不过滤、不降权。
