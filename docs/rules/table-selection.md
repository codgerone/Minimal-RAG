# 表格提取与选优

> **规则摘要**
> - Docling 解析时识别出的每一张表格，就是一个"表格位置"（slot）。
> - 四个工具共九种策略各自在每一页找表格，找到的都算"候选表"。
> - 候选表和某个表格位置在同一页、并且双向重叠足够多（候选框有 ≥65% 落在位置内，位置框有 ≥77% 被候选覆盖），才算这个位置的候选。
> - 同一位置的候选，用四项指标两两比较：文本覆盖、关键数字完整、行列形状共识、空白异常。四项相对分的平均就是总分，总分最高者胜出。
> - 没有候选的位置，保留 Docling 自己识别的表格结构（"原生表格"）。
> - 每个表格位置最终恰好产出一张表，不会重复，也不会丢失。

代码：`rag/ingest/tables/`（`extractors.py` 接入工具，`grouping.py` 负责准入与分组，`scoring.py` 负责评分，`select.py` 负责编排）。

## 1. 提取

| 工具 | 策略 |
|---|---|
| PyMuPDF | lines、lines_strict、text |
| Camelot | lattice、stream、network、hybrid |
| Docling | accurate（复用解析时的同一次转换，不重复转换 PDF） |
| Unstructured | hi_res（逐页切出单页 PDF 再识别） |

- 每种策略都会执行，不会因为前面的策略已经找到表格就跳过。
- 某一页失败只记录这一页，其他页照常处理。
- 每张候选表统一转换为同一种结构：单元格文字、零基半开区间的行列范围、跨度、来源。合并单元格按一个物理格保存。
- 坐标统一换算到"PDF 页面左上原点、单位 pt"。Camelot 的左下原点要翻转；Unstructured 的像素坐标按页面宽高比例缩放。页面尺寸与 PDF 相差超过 1.0 pt 的候选不参与几何比较。

## 2. 准入（候选归属哪个表格位置）

设候选框为 C、位置框为 S（同页多个框时取最小外接矩形）：

```
candidate_coverage = area(C ∩ S) / area(C)   ≥ 0.65
slot_coverage      = area(C ∩ S) / area(S)   ≥ 0.77
```

两项同时满足才算匹配；比较时加 1e-12 的容差。

| 情况 | 结果 |
|---|---|
| 候选跨页、缺坐标或坐标无效 | 暂缓，不参与比较 |
| Docling 在该页执行失败 | 暂缓（没有可靠的位置来源） |
| 同页没有表格位置 | 拒绝 |
| 与所有位置都重叠不足 | 拒绝 |
| 恰好匹配一个位置 | **准入**，归入该位置 |
| 同时匹配多个位置 | 拒绝（无法归属） |

跨页、缺框或坐标无效的表格位置会被暂缓，不接收候选，直接采用原生表格。

## 3. 评分

**参照文本**：用 PyMuPDF 读取原 PDF 中中心点落在位置框内的单词，作为"标准答案"。两边统一做规范化：NFKC、去首尾空白、转小写；数字之间的各种撇号统一处理。

| 指标 | 计算 | 方向 |
|---|---|---|
| 文本覆盖 text_f1 | 候选 token 与参照 token（多重集）的 F1 | 越高越好 |
| 关键数字完整 critical_token_integrity | 参照中含数字的 token，被候选完整包含的比例 | 越高越好 |
| 行列形状共识 shape_support | 同组中与它行列数相同的候选占比 | 越高越好 |
| 空白异常 blank_anomaly | max(0, 本候选空白格比例 − 组内参照空白比例) | 越低越好 |

**相对分**：每项指标在组内两两比较，胜得 1、平得 0.5、负得 0，再除以对手数（数值差 ≤1e-12 视为相等）。组内只有一个候选时，各项都记 1。

**总分**：四项相对分各乘 0.25 后相加。

**决胜**：总分最高者胜。若并列，按工具优先级 pymupdf > camelot > docling > unstructured，再按候选 ID 排序。

## 4. 已知限制

- 跨页表格不做拼接，交给 Docling 原生结构。
- 扫描件没有文本层，参照文本为空，不在支持范围内。
- 准入阈值来自 `experiments/` 中的校准实验，只用 5 份 PDF 验证过。
