# 表格提取与选优

> **规则摘要**
> - Docling 解析时识别出的每一张表格，就是一个"表格位置"（slot）。
> - 四个工具共九种策略各自在每一页找表格，找到的都算"候选表"。
> - 候选表和某个表格位置在同一页、并且双向重叠足够多（候选框有 ≥65% 落在位置内，位置框有 ≥77% 被候选覆盖），才算这个位置的候选。
> - 同一位置的候选，用四项指标两两比较：文本覆盖、关键数字完整、行列形状共识、空白异常。四项相对分的平均就是总分，总分最高者胜出。
> - 没有候选的位置，保留 Docling 自己识别的表格结构（"原生表格"）。
> - 每个表格位置最终恰好产出一张表，不会重复，也不会丢失。

代码：`rag/ingest/tables/`（`extractors.py` 接入工具，`grouping.py` 负责准入与分组，`scoring.py` 负责评分，`select.py` 负责编排）。

## 1. 提取

| 工具 | 策略 |
|---|---|
| PyMuPDF | lines、lines_strict、text |
| Camelot | lattice、stream、network、hybrid |
| Docling | accurate（复用解析时的同一次转换，不重复转换 PDF） |
| Unstructured | hi_res（逐页切出单页 PDF 再识别） |

- 每种策略都会执行，不会因为前面的策略已经找到表格就跳过。
- 某一页失败只记录这一页，其他页照常处理。
- 每张候选表统一转换为同一种结构：单元格文字、零基半开区间的行列范围、跨度、来源。合并单元格按一个物理格保存。
- 坐标统一换算到"PDF 页面左上原点、单位 pt"。Camelot 的左下原点要翻转；Unstructured 的像素坐标按页面宽高比例缩放。页面尺寸与 PDF 相差超过 1.0 pt 的候选不参与几何比较。

## 2. 准入（候选归属哪个表格位置）

设候选框为 C、位置框为 S（同页多个框时取最小外接矩形）：

```
candidate_coverage = area(C ∩ S) / area(C)   ≥ 0.65
slot_coverage      = area(C ∩ S) / area(S)   ≥ 0.77
```

两项同时满足才算匹配；比较时加 1e-12 的容差。

| 情况 | 结果 |
|---|---|
| 候选跨页、缺坐标或坐标无效 | 暂缓，不参与比较 |
| Docling 在该页执行失败 | 暂缓（没有可靠的位置来源） |
| 同页没有表格位置 | 拒绝 |
| 与所有位置都重叠不足 | 拒绝 |
| 恰好匹配一个位置 | **准入**，归入该位置 |
| 同时匹配多个位置 | 拒绝（无法归属） |

跨页、缺框或坐标无效的表格位置会被暂缓，不接收候选，直接采用原生表格。

## 3. 评分

评分分三步：每个候选先算出四项**原始指标**；同组候选再逐项两两比较，折算成**相对分**；四项相对分取平均得到**总分**。代码见 `rag/ingest/tables/scoring.py`。

### 3.1 两边的 token 怎么来

- **参照 token（R）**：用 PyMuPDF 读取原 PDF 这一页的单词（`get_text("words")`），中心点落在表格位置框内的单词才算。**一个单词就是一个 token**。
- **候选 token（C）**：逐个读取候选表的单元格文字，按空白切分。每个单元格单独切，不会和相邻单元格拼接。
- **规范化**（两边相同）：NFKC 规范化、去首尾空白、转小写。夹在两个数字之间的各种撇号（`' ’ ´` 等）统一成 `'`，其两侧的空白去掉，例如 `1´ 131` 与 `1’131` 视为相同。其他标点保留，逗号和小数点不互换。
- R 和 C 都是**多重集**：同一个 token 出现几次就计几次。下文的 count_R(t) 表示 token t 在 R 中出现的次数，|R| 表示 R 的总个数（含重复）。

### 3.2 四项原始指标

**① 文本覆盖 text_f1**：候选和原文的文字吻合程度，越高越好。

```
M（匹配数） = Σ_t min(count_R(t), count_C(t))      对每个 token 取两边出现次数的较小值后求和
precision  = M / |C|                                候选的文字里有多少是原文中的
recall     = M / |R|                                原文的文字有多少被候选找回
F1         = 2 × precision × recall / (precision + recall)  =  2M / (|R| + |C|)
```

边界情况：参照为空（这片区域没有文字）时不可评价；候选为空，或 precision + recall = 0 时，F1 = 0。

**② 关键数字完整 critical_token_integrity**：原文中的数字有没有被完整提取，越高越好。

```
K（关键 token）= R 中至少含一个数字字符的 token（多重集）
integrity     = Σ_t min(count_K(t), count_C(t)) / |K|
```

匹配要求**整个 token 完全相同**：`968,000.00` 被切成 `968,000` 和 `.00` 时，不算匹配。原文中没有数字时，记为"不适用"。

**③ 行列形状共识 shape_support**：有多少个工具得出了相同的行列数，越高越好。

```
shape_support = 同组中与本候选 (行数, 列数) 完全相同的候选个数（含自己） / 同组候选总数
```

行数或列数缺失、不是正整数时记 0。

**④ 空白异常 blank_anomaly**：空白格是否比同组其他候选明显多，越低越好。

```
本候选空白率 = 1 − 有文字的格覆盖的网格位置数 / (行数 × 列数)
参照空白率   = 同组所有可计算候选的空白率中，出现次数 ≥ 2 且唯一的众数；没有这样的众数时取最小值
blank_anomaly = max(0, 本候选空白率 − 参照空白率)
```

文字去掉空白后不为空，才算"有文字"。合并单元格覆盖的所有位置都算有文字，重叠位置只计一次。空白率按分数精确比较，不先四舍五入。低于参照空白率不加分，异常记 0。网格无法建立（缺行列数、单元格位置无效或互相重叠）时，记为"不可评价"。

### 3.3 相对分与总分

每项指标都在组内把候选两两比较（两个值相差 ≤ 1e-12 视为相等）：

| 比较结果 | 得分 |
|---|---|
| 更优（①②③ 数值更大；④ 数值更小） | 1 |
| 相等，或双方都不可评价/不适用 | 0.5 |
| 更差 | 0 |
| 只有一方可评价 | 可评价的一方得 1，另一方得 0 |

```
某项相对分 = (胜场数 + 0.5 × 平局数) / (组内候选数 − 1)       组内只有 1 个候选时记 1
总分       = 0.25 × (相对分① + 相对分② + 相对分③ + 相对分④)
```

相对分只看排名先后，不看差距大小：`1.00` 比 `0.99` 和 `1.00` 比 `0.10` 都只算赢一场。没有任何单项淘汰线，也不跨组比较总分。

**决胜**：总分最高者胜出。总分并列时，依次按工具优先级 pymupdf > camelot > docling > unstructured、候选 ID 升序决定。审核页会注明胜出原因（总分最高 / 按工具优先级 / 按候选编号）。

### 3.4 算例

某个表格位置的原文是一行 `Qty 10,000 USD 96.80 USD 968,000.00`。同组有 4 个候选，以候选 A 为例，它把金额切进了两个单元格：`Qty | 10,000 | USD 96.80 | USD 968,000 | .00`。

| 指标 | 计算 |
|---|---|
| ① 文本覆盖 | R = {qty, 10,000, usd×2, 96.80, 968,000.00}，\|R\| = 6；C = {qty, 10,000, usd×2, 96.80, 968,000, .00}，\|C\| = 7；匹配 M = 1 + 1 + 2 + 1 = 5。precision = 5/7 = 0.714，recall = 5/6 = 0.833，F1 = 2×5 / (6+7) = **0.769** |
| ② 关键数字 | K = {10,000, 96.80, 968,000.00}，A 完整包含其中 2 个 → 2/3 = **0.667** |
| ③ 形状共识 | 4 个候选的形状分别是 1×5、1×5、1×5、2×5，A 是 1×5 → 3/4 = **0.75** |
| ④ 空白异常 | A 没有空白，空白率 0；组内空白率 0、0、0、1/10，众数为 0 → **0** |

如果 A 的四项原始指标在组内分别排第 1（独占）、并列第 1（与 1 个候选并列）、并列第 1（与 2 个候选并列）、并列第 1（与 2 个候选并列）：

```
相对分① = (3 + 0.5×0) / 3 = 1.000
相对分② = (2 + 0.5×1) / 3 = 0.833
相对分③ = (1 + 0.5×2) / 3 = 0.667
相对分④ = (1 + 0.5×2) / 3 = 0.667
总分     = 0.25 × (1.000 + 0.833 + 0.667 + 0.667) = 0.792
```

审核页的评分表列出的是四项**原始指标**和**总分**，相对分不单独展示，可在 `.rag/indexes/<配置>/documents/<文档>/tables.json` 的 `scoring` 中查到。

## 4. 已知限制

- 跨页表格不做拼接，交给 Docling 原生结构。
- 扫描件没有文本层，参照文本为空，不在支持范围内。
- 准入阈值来自 `experiments/` 中的校准实验，只用 5 份 PDF 验证过。
