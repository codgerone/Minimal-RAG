# 关键词检索（BM25）与混合检索

> **规则摘要**
> - 配置含 `[lexical]` 一节时，入库为每个 chunk 建 BM25 倒排索引（`.rag/indexes/<配置名>/bm25.sqlite`）；`[lexical]` 的设置进入构建指纹。
> - 问题与 chunk 经同一分析器变为词：规范化 → 切词 → 去停用词（可关）→ 词干化（可开）。
> - BM25 的 IDF 与平均 chunk 长度按全库统计，检索范围只决定哪些 chunk 参与排序。
> - `hybrid` 用倒数排名融合（RRF）合并向量排名与 BM25 排名。
> - 检索器 `bm25`、`hybrid` 要求配置 `[lexical]`；`semantic` 不使用 BM25 索引。

代码：`rag/index/analyzer.py`（分析器）、`rag/index/lexical.py`（索引与打分）、`rag/query/retriever.py`（检索器）。

## 分析器

1. **规范化**：NFKC 归一，统一小写，去掉组合附加符号（重音）。
2. **汉字**：每个汉字单独成词，并与相邻的非汉字字符断开。
3. **切词**：由 Unicode 字母或数字组成、相邻两段之间以 `-` `.` `/` `,` 中的一个字符相连的最长字符串记为一个词；含连接符时，再把按连接符拆出的每一段各记为一个词。
4. **去停用词**（`stopwords`，默认开启）：去掉出现在西班牙文或英文停用词表中的词。两张表合并使用，问题与 chunk 相同。停用词表取自 Snowball 项目，存放在 `rag/index/stopwords/`。
5. **词干化**（`stemming`，默认开启）：只由字母组成的词，用 Snowball 词干器取词干；含数字或连接符的词不变。

词频为同一个词在 chunk 中出现的次数；chunk 长度为它的词数（含拆出的各段）。

## 文档语言

入库时，对一份文档全部 chunk 的切词结果（第 3 步），分别数出属于西班牙文停用词表和英文停用词表的词数；西班牙文多于英文时记为西班牙文，否则记为英文。这份文档的 chunk 都按该语言词干化。不开词干化时，语言只作记录。

问题不判定语言：分别按西班牙文、英文得到两组词（不开词干化时两组相同），每个 chunk 只用自己语言的那一组计分。同一组内重复的词只计一次。

## BM25 打分

chunk d 对问题的得分为问题词 t 的逐项之和，只计 d 中出现的词：

```
score(d) = Σ idf(t) · tf(t,d) · (k1 + 1) / (tf(t,d) + k1 · (1 − b + b · |d| / avgdl))
idf(t)   = ln(1 + (N − n(t) + 0.5) / (n(t) + 0.5))
```

- `tf(t,d)`：词频；`|d|`：chunk 长度；`N`：全库 chunk 数；`avgdl`：全库 chunk 长度之和 / N；`n(t)`：全库含 t 的 chunk 数。
- `k1 = 1.2`，`b = 0.75`，为固定常数。
- 检索范围内得分大于 0 的 chunk 按（得分降序，chunk ID 升序）排名，名次从 1 起。

## 混合检索（hybrid）

1. 向量排名：检索范围内全部 chunk 按（余弦距离升序，chunk ID 升序）排名。
2. BM25 排名：同上一节，只含得分大于 0 的 chunk。
3. 融合得分 = 1 / (60 + 向量名次) + 1 / (60 + BM25 名次)；不在 BM25 排名中的 chunk 只计第一项。
4. 按（融合得分降序，chunk ID 升序）取前 K 个。

每条命中记录向量名次与相似度、BM25 名次与得分（无则为空）、融合得分。

## 一致性

BM25 索引与向量库并列，按同一规则维护：单个文档入库时先替换向量、再替换该文档的 BM25 记录（一个 SQLite 事务），最后写 manifest；全量重建时两者都先清空。`status` 中，BM25 索引里某文档的 chunk ID 集合与 manifest 不一致，该文档记为"索引不完整"。
