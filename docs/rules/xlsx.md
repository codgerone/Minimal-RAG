# Excel（.xlsx）解析

> **规则摘要**
> - openpyxl 读两遍：缓存值（Excel 保存时算出的值）与公式。只读文件中存了的格。全部工作表都读，含隐藏与深度隐藏的；图表工作表跳过。读取模块只给事实，保存为 `parse-native.json`；解析器与 `anchors` 共用它，格的文字必然一致。
> - 写进 chunk 的是**显示值**：缓存值按单元格的数字格式写出，与 Excel 屏幕上看到的一致。不重新计算公式；公式文本（含跨工作表引用）只作记录。
> - 区域只按几何切分，不解读内容：共边相连的占用格（有值的格、合并区域覆盖的格、有边框的空格）为一个区域；外接矩形重叠、或首末行都相同且都至少 2 行的区域合并。至少 2 行 2 列的是表格（`parser_exact`），其余是正文。
> - 表格上方的标题、表内的分节行、表格旁的备注都留在几何给出的位置，含义由表格结构环节处理。
> - 位置为文件内地址：工作表 + 行 + 列，文字位置为格内字符区间。

代码：`rag/ingest/xlsx/reader.py`（读取与地址）、`rag/ingest/xlsx/display.py`（显示值）、`rag/ingest/xlsx/regions.py`（区域切分）、`rag/ingest/parsers/xlsx_native.py`（解析器）。

## 读取

- 不用 `read_only` 模式（读不到合并单元格）。只遍历文件中存了的格，不按已用范围遍历。
- 每个格记：显示值、缓存值、公式文本、数字格式与其编号、显示值是否按 General 写出及原因、是否为没有缓存值的公式。
- 每个工作表记：在工作簿中的序号、名称、状态（显示 / 隐藏 / 深度隐藏）、合并区域、隐藏的行、隐藏的列（列宽记录的整个范围）、Table 对象（范围与表头行数）、有边框（任一边有线型）的格、图片数、图表数。
- 隐藏的工作表、行、列照常入库，chunk 文字中不加标记，审核页标出。
- 图片、图表、图表工作表不入库，各记一条警告；批注、数据验证、条件格式不入库。

## 地址

| 对象 | 写法 |
|---|---|
| 工作表名 | `sheet<N>#name` |
| 单元格 | `sheet<N>/r<行>c<列>` |
| 表格 | `sheet<N>/r<首行>c<首列>:r<末行>c<末列>` |

`<N>` 为工作表在工作簿中的序号（含图表工作表），行、列从 1 起。字符区间按格的显示值的 Python 字符串下标计，左闭右开。位置标签为 `工作表名!A1` 或 `工作表名!A1:C5`。

## 显示值

| 值 | 显示值 |
|---|---|
| 空 | 空 |
| 文字 | 原样（富文本取纯文字） |
| 布尔 | `TRUE` / `FALSE` |
| 错误值 | 原样 |
| 有公式、没有缓存值 | 空，记警告 |
| 数字、日期 | 按数字格式 |

数字格式：
- 数字先取 15 位有效数字（Excel 保存的精度），按四舍五入（远离零）舍入到格式的小数位数。
- 按 `;` 分成正数、负数、零、文字四节。只有一节时负数在前面加 `-`；有负数节时负数按绝对值写，符号由该节给出；有零节时零用零节。
- 支持的记号：`0`、`#`、`?`（数位；不足的位分别写 `0`、不写、写空格）、千分位 `,`、`.`、`%`、`E+` / `E-`、引号中的文字、`\` 转义的字符、`_x`（一个空格）、`*x`（重复填充，忽略）、`[$符号-区域码]`（写出符号）、颜色（忽略）、`@`（数字按 General 写出）、`General`。
- 按 General 写出并记原因：带条件的格式、最后一个数位之后的逗号（缩放）、分数、经过时间 `[h]`、其他不支持的记号、未知的内置格式编号、负数日期。
- 显示值去掉首尾的空白。
- 内置格式按格式编号判断：14 号写成 `yyyy-mm-dd`，22 号写成 `yyyy-mm-dd hh:mm`（这两种的显示随操作系统的区域设置而变）。
- General：整数不带小数；其他数字最多 11 位有效数字，去掉末尾的 0，不加千分位；绝对值 ≥ 1e11 的非整数与 < 1e-9 的数写成 `1.23457E+11`。
- 日期与时间：`y`/`yy`（两位年）、`yyy`/`yyyy`（四位年）、`m`、`mm`、`mmm`、`mmmm`、`mmmmm`、`d`、`dd`、`ddd`、`dddd`、`h`、`hh`、`m`/`mm`（紧跟在 `h` 之后或紧接 `s` 之前时为分钟）、`s`、`ss`、`AM/PM`、`A/P`（出现时用 12 小时制）。区域码的语言为西班牙文、英文、中文时，月份名与星期名用该语言，否则用英文。
- 小数点、千分位固定为 `.` 与 `,`。

## 区域切分

在每个工作表上：
1. Table 对象的范围为一个区域，其中的格不参与后续切分。
2. 占用格为：有显示值的格；第一格有显示值的合并区域覆盖的全部格；有边框的空格。共用一条边的占用格相连，每个连通的集合为一个区域。
3. 两个区域满足以下之一即合并，反复进行到不能再合并：外接矩形重叠；首行相同、末行相同，且都至少 2 行。
4. 没有值（只由空的有边框格组成）的区域丢弃。
5. 分类，按区域中有值的格（合并区域只算第一格）：都在同一行 → 一段正文，各格的显示值去掉首尾空白后以 ` | ` 连接；都在同一列 → 每格一段正文；否则为表格，网格取外接矩形，未占用的位置为空格，完全落在矩形内的合并区域（包括空的）保留为合并格。Table 对象总是表格，其表头行数作为事实记在格上，表头仍按规则判定。

边框只用来确定表格覆盖哪些格，不用来推断表头、分节等语义。已知局限：同一张逻辑表左右两块高度不同、又没有边框时，切成两张表。

## 阅读顺序

工作表按工作簿顺序，没有任何显示值的工作表不入库。每个工作表的第一个元素是以工作表名为文字的标题；之后区域按首行、再按首列排列。`PrimaryDocument.page_count` 记工作表数。
