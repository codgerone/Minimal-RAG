# 查询侧模块：分解、去编码、写法、融合与合并

## 规则摘要

- 查询侧模块把一个问题变成若干条检索文本，各检索一次，再合成每个问题的排名，必要时合成一个返回顺序。
- 现行 `ask`、`chat`、`eval` 不使用这些模块：用原问题检索一次。模块只在 `query-compare`（查询侧对比页）中使用，V3.15 的多轮检索复用其中的去编码、写法与融合（[决策 015](../decisions/015-query-modules.md)）。
- **规划**由 LLM 完成，分两步：
  - 分解（可选）：得到问题列表；
  - 写法：为列表中的每个问题写出改写、译文、HyDE、step-back。
- **去编码**、**融合**、**合并**由代码完成，不调用 LLM。

## 规划

**问题列表**：开分解时为分解调用返回的问题（去重，保持顺序），否则只有原问题。每个问题带编号 `Q1`、`Q2`……，作为写法调用的输入。

**分解**的要求（提示词 `query_plan_v9`）：
- 每个明确问到的信息项写一个问题。并列或依次列出的项是不同的项；先提总要求、再列出应包括的内容时，列出的部分是信息项。
- 问题用描述指代一个对象、且要先知道是哪一个才能找到答案时，另写一个问题问它是哪一个。
- 问能从文档读到的事实，不问由事实计算出的结论；某项是计算结论时，改问它所依据的事实。
- 每个问题独立成立：原问题中适用于它的限定条件（实体、条件、时间范围、所指文档）逐字写入；只在前文出现一次、后文省略的限定条件，写入它适用的每个问题；后文的简称写成前文给出的全称。
- 不加原问题既没有问到、也不需要的问题。
- 用原问题的语言写。

**写法**（提示词 `query_plan_v8`），每种都由问题本身直接写出，不由另一种写法派生：

| 写法 | 要求 |
|---|---|
| 改写 | 问题的语言；写成陈述或名词短语，去掉疑问词与赘语；名称、编码、数字、引用的术语原样保留 |
| 翻译 | 译成检索范围内每种文档语言，问题已是该语言时跳过；用该语言文档的术语；名称、编码、数字不译 |
| HyDE | 每种文档语言一段，写成答案在这类文档中出现的样子；未知的值用方括号占位；问题中给出的名称原样保留 |
| step-back | 问题的语言；去掉把问题限定到单个实例（一个实体、项目或时期）的限定条件，前提是各实例的答案写在同一处；不问一般知识或这类文档通常包含什么 |

**写法的语言**：改写、step-back 可用问题语言写（上表），也可用文档语言写：
- 文档语言的改写、step-back 由另一次调用写出（提示词 `query_plan_lang_v1`），输入同一个问题列表；要求与上表相同，只是用检索范围内每种文档语言各写一段、用该语言文档的术语，名称、编码、数字照写；问题已是某种文档语言时跳过该语言。
- 检索时三选一：问题语言、文档语言、两种。文档语言中被跳过的语言由问题语言的文本代替；两种为问题语言与文档语言的全部文本。

- 文档语言是检索范围内各文档入库时判定的语言，由代码填入写法提示词。
- 提示词只描述任务本身，不写特定领域、文档类型或测试集中的例子。

**校验与降级**：
- 分解：必须至少有一个问题，且没有空问题。
- 写法：必须每个编号恰好一条；改写、step-back 非空；译文每种语言至多一段且非空；HyDE 每种文档语言恰好一段且非空。
- 文档语言写法：必须每个编号恰好一条；改写、step-back 每种语言至多一段且非空。
- 不合格时，把未通过的检查项交给 LLM，重试一次。
- 仍不合格：分解退回原问题；写法退回只用问题原句；文档语言写法不加文本。都记为规划降级，并写明原因。

**缓存**：每次调用按（模型、消息、输出格式、推理强度、提示词版本）缓存在 `.rag/llm-cache/`。独立生成另带生成编号，与第 0 次分开缓存。

## 去编码

开启时，每个问题的每条检索文本在检索前删去文档过滤识别出的标识编码：
- 按 [rules/document-filter.md](document-filter.md) 的规范化在文字中定位编码，删去后合并多余空白；
- 编码前后的说明词不删；
- 写法中的编码写法与问题不同、按规范化定位不到时保留。

去编码不改变检索范围。原问题一路不去编码。

## 检索与融合

- **检索文本**：每个问题从原句与启用的写法中取。一种写法有几段文字时（按文档语言），每段算一条。
- **检索**：每条检索文本检索一次，得到检索范围内全部返回单元的排名，不截断。
- **融合**：同一问题的多条排名按返回单元用 RRF 融合：

  得分 = Σ 1 / (60 + 名次)

  得分相同时按单元标识排序。单元在各条排名中都出现时，取名次最好的那次作为它的代表。
- **不融合**：只能选一种写法，用它的文字代替原句检索；这种写法对一个问题有多段文字时（按语言），各段的排名按上式 RRF 融合；没有文字时该配置不可用。
- **检索次数**：每题 = 各问题的检索文本条数之和；开原问题一路时加 1。

## 跨问题合并（只在分解时）

| 方式 | 规则 |
|---|---|
| 轮流取 | 按问题顺序，每圈从每个问题的排名中取下一个尚未入选的单元，直到候选取尽 |
| 全局 RRF | 各问题的排名按返回单元用 RRF 合成一个排名；每个单元记在它名次最好的问题下，相同时记在靠前的问题下 |
| 不合并 | 没有返回顺序，只用于评估（[rules/evaluation.md](evaluation.md)"查询侧的比较"） |

**原问题一路**：选了合并方式时可开。原问题原句（带编码，不经过写法与去编码）另检索一次：轮流取时排在每圈最后；全局 RRF 时作为一条排名参与合成。

返回顺序取到候选取尽为止，预算 K 取其前 K 个；K 是整个原问题返回的单元总数。
