# 分块

> **规则摘要**
> - `characters`（搭配 `pymupdf_pages`）：每页单独切分，不跨页；每块最多 300 个字符，相邻块重叠 50 个字符，优先在段落、换行、句号、分号、逗号、空格处断开。
> - `structured_tokens`（搭配 `docling_layout`）：按文档的阅读顺序处理。相邻的普通文本合并成块，列表和表格各自单独成块。每块不超过 E5 模型实际的 **512 token** 上限（包含 `passage: ` 前缀）。
> - 超长内容切开时会补上下文：普通文本保留约 32 token 的重叠；表格的每个分块重复表头行，跨块的纵向合并单元格补出原值；列表重复上级列表项。原文不会丢失。
> - chunk ID 统一为 `<文档ID>-c0001` 这种格式；每个 chunk 都记录它来自哪个解析节点、在原文中的位置和页码。

代码：`rag/ingest/chunkers/`。

## characters

- 使用 LangChain 的 RecursiveCharacterTextSplitter，分隔符依次为 `\n\n`、`\n`、`. `、`; `、`, `、空格、逐字符；`keep_separator="end"`。
- 每块去掉首尾空白；与上一块完全相同的块会被丢弃。
- 参数：`chunk_size`（默认 300）、`chunk_overlap`（默认 50），都按 Python 字符数计算。

## structured_tokens

**普通文本**：按阅读顺序把相邻的文本节点用空行拼接，直到再加一个节点就会超过上限。单个节点本身超限时，按以下边界从粗到细切分：

```
连续空行 → 换行 → 句末标点（。！？.!?）→ 分号 → 冒号 → 逗号 → 空白 → 逐字符
```

后一段开头重复前一段末尾不超过 `overlap_tokens`（默认 32）个 token 的内容；标题不做重叠。

**列表**：每项写成 `缩进 + 序号/“-” + 文本`，尽量把完整的项放在同一块。嵌套项单独成块时，会带上它的上级项。上级项太长放不下时，用 `〔上级项：第N项〕` 代替。

**表格**：按[表格文本化](table-text.md)得到的行，逐行放入同一块，直到放不下为止。新块开头重复表格的表头行（`row_text_v1` 为 `表头未确定。`，`markdown_rows_v1` 为列名行；只在表头行之后的行开块时重复）。纵向合并单元格跨块时：

- `row_text_v1`：新块开头重复仍在生效的纵向合并说明。
- `markdown_rows_v1`：开启新块的那一行，被上方数据行起始的纵向合并单元格覆盖的位置，最左一格写作 `↑ 原值`，其余写 `←`；块中间的行不改写。

重复的表头行和补出的合并值都登记为重复上下文，来源指向原表头行或合并单元格的左上角。单行就超限时，在行内切分，并加上 `〔表格 X，第N行，字段〕` 定位。

**校验**：每块都会按实际模型 tokenizer 重新计数，超过上限则该文档入库失败。

参数：`max_tokens`（默认 512）、`overlap_tokens`（默认 32）。
