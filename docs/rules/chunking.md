# 分块

> **规则摘要**
> - `characters`（搭配 `pymupdf_pages`）：每页单独切分，不跨页；每块最多 300 个字符，相邻块重叠 50 个字符，优先在段落、换行、句号、分号、逗号、空格处断开。
> - `structured_tokens`（搭配 `docling_layout`）：按文档的阅读顺序处理。相邻的普通文本和列表项按预算合并成块，表格单独成块。每块不超过 **512 token**，固定按 multilingual-e5 的分词器计数（包含 `passage: ` 前缀），与所用编码器无关。
> - 超长内容切开时会补上下文：普通文本保留约 32 token 的重叠；表格的每个分块重复表头行，跨块的纵向合并单元格补出原值；列表项开新块时重复上级列表项。原文不会丢失。
> - chunk ID 统一为 `<文档ID>-c0001` 这种格式；每个 chunk 都记录它来自哪个解析节点、在原文中的位置和页码。

代码：`rag/ingest/chunkers/`。

## characters

- 使用 LangChain 的 RecursiveCharacterTextSplitter，分隔符依次为 `\n\n`、`\n`、`. `、`; `、`, `、空格、逐字符；`keep_separator="end"`。
- 每块去掉首尾空白；与上一块完全相同的块会被丢弃。
- 参数：`chunk_size`（默认 300）、`chunk_overlap`（默认 50），都按 Python 字符数计算。

## structured_tokens

**普通文本与列表**：按阅读顺序，把文本节点和列表项当作同一串单元，依次放入当前块；再放一个单元就超过上限时，当前块结束，从这个单元开新块。表格结束当前块。

- 连接：同一列表的相邻项之间用换行，其余单元之间用空行。
- 列表项写成 `缩进 + 序号/“-” + 文本`，是不可拆的单元，列表在项与项之间断开。
- 列表项开新块时，块开头重复它的上级项（解析器给出的嵌套关系），登记为重复上下文；上级项放不下时，用 `〔上级项：第N项〕` 代替。
- 含列表项的块类型记为"含列表"，其余为"正文"。

单个文本节点本身超限时，单独按以下边界从粗到细切分：

```
连续空行 → 换行 → 句末标点（。！？.!?）→ 分号 → 冒号 → 逗号 → 空白 → 逐字符
```

后一段开头重复前一段末尾不超过 `overlap_tokens`（默认 32）个 token 的内容；标题不做重叠。单个列表项本身超限时，按同样的边界在项内切分，每段开头写上它的序号；有上级项时再加 `〔List 编号，父项路径见完整列表〕` 定位。

**表格**：按[表格文本化](table-text.md)得到的行，逐行放入同一块，直到放不下为止。

- 表格有单独的表头行时（`markdown_rows_v1` 认出表头），表头行之后的行开启新块时，块开头重复表头行。
- 开启新块的那一行，被上方数据行起始的纵向合并单元格覆盖的位置，最左一格写作 `↑ 原值`（`labeled_rows_v1` 写作 `列名: ↑ 原值`），其余写 `←`；块中间的行不改写。
- 重复的表头行和补出的合并值都登记为重复上下文，来源指向原表头行或合并单元格的左上角，计入该块的来源区域。
- 单行就超限时，在行内切分，每段开头加 `〔表格 X，第N行〕` 定位；定位文字没有来源区域。

**校验**：每块都会按 multilingual-e5 分词器重新计数，超过上限则该文档入库失败。编码时，编码器再用自己的分词器检查每块不超过它的输入上限（bge-m3 为 8192），超过则入库失败，不做截断。

计数固定用一个分词器，是为了换编码器时 chunk 保持不变，见[决策 008](../decisions/008-embedder-bge-m3.md)。

参数：`max_tokens`（默认 512）、`overlap_tokens`（默认 32）。
