# Word（.docx）解析

> **规则摘要**
> - Word 文件直接读 XML，不转 PDF。读取模块只给出文件中的事实（各部件、节、注释，每个块的文字、样式、编号、大纲级别、注释引用，表格网格与合并，空段落也在内），保存为 `parse-native.json`；标题、列表、表格、阅读顺序由解析器 `docx_native` 判定。
> - 位置不用页码，用文件内地址：部件 + 块号 [+ 单元格 + 格内段号] [+ 文本框段号]，文字位置为该地址文字中的字符区间。解析器与 `anchors` 共用读取模块，地址必然一致。
> - 标题只认样式与大纲级别，不按字体推断；编号文字按 `numbering.xml` 计算，记为单独的 `#label` 部分。
> - 网格列数 ≥ 2 的表格由文件直接给出（`parser_exact`），不做表格提取、选优与续表判定；只有 1 列的表格视为排版框，格内内容按正文读出。
> - .docx 不记录分页：阅读顺序逐节排列，页眉页脚按节放，脚注、尾注跟在第一次引用处之后。

代码：`rag/ingest/docx/reader.py`（读取与地址）、`rag/ingest/docx/numbering.py`（自动编号）、`rag/ingest/parsers/docx_native.py`（解析器）。

## 地址

| 部分 | 写法 | 规则 |
|---|---|---|
| 部件 | `body`、`header<n>`、`footer<n>`、`footnotes`、`endnotes` | `<n>` 取 `word/` 下部件文件名中的序号 |
| 块号 | `/<k>` | 部件内段落 `w:p` 与表格 `w:tbl` 按出现顺序从 0 编号；内容控件 `w:sdt`、`w:customXml`、`w:smartTag` 不计号，内容在原位展开；空段落也计号。脚注、尾注的块号在整个部件内连续编号 |
| 单元格 | `/r<i>c<j>/<k>` | 单元格的起始行号与起始网格列号（从 0 起），再加格内块号；合并单元格用起始格 |
| 文本框 | `/t<k>` | 接在锚定段落的地址后，`<k>` 为文本框内的块号 |
| 编号文字 | `#label` | 接在段落地址后 |

字符区间按该地址文字（文字规则写出、未去首尾空白）的 Python 字符串下标计，左闭右开。

位置标签（审核页、检索结果、评估页显示用）：正文块为"第 k+1 块"，表格为"表 N"（解析器给出的表格序号），页眉、页脚、脚注、尾注为部件类别名。

## 文字规则

- 依次拼接 `w:t`；`w:tab`、`w:ptab` 写成一个空格；`w:br`、`w:cr` 写成换行；`w:sym` 写成对应字符；`w:noBreakHyphen` 写成 `-`；`w:softHyphen` 不写。
- 修订：计入插入、移入的文字，不计删除、移出的文字（接受全部修订）。
- 域：只计域结果，不计域代码；域可跨段落。
- `mc:AlternateContent` 只取 `mc:Choice`。文本框的内容作为独立的块，放在锚定段落之后。
- 图片、图表、OLE 对象不入库，各记一条警告。
- 脚注、尾注的分隔符不读。

## 元素

- **标题**：段落自身或样式继承链上的大纲级别 `w:outlineLvl` 为 0–8，或样式名（`w:name`，不分大小写，不用 `w:styleId`）为 `title`、`heading 1`–`heading 9`。不按加粗、字号推断。
- **列表项**：带自动编号或项目符号、且不是标题的正文段落。层级取 `w:ilvl`，编号文字为序号，项目符号的序号为空。相邻的列表项组成一个列表；父项为前面最近一个层级更低的项。
- **带编号的段落**（标题、页眉等）：文字写成"编号文字 + 空格 + 段落文字"，编号文字的位置为 `#label`。
- **目录**：样式名为 `toc 1`–`toc 9` 的段落，以及 TOC 域结果中的段落，不入库。
- **页眉、页脚、脚注、尾注**：分别为页眉、页脚、脚注类型的文字；尾注记为脚注类型。
- 去掉首尾空白后为空、且没有编号的段落不产生元素，块号照常计。

## 阅读顺序

1. 按节依次读：节 = 正文中到下一个 `w:sectPr` 为止的块（段落属性中的 `w:sectPr` 结束所在段落的节，正文末尾的 `w:sectPr` 结束最后一节）。
2. 每节先读该节引用的页眉（首页、默认、偶数页的顺序），再读该节正文，最后读该节引用的页脚。已读过的部件、文字与已读部件完全相同的部件不再读；没有引用的节沿用前一节，不重复读。
3. 脚注、尾注放在第一次引用它的段落之后；引用在列表项中时放在整个列表之后，在表格中时放在整张表之后。没有被引用的注释放在最后一节正文之后。

## 自动编号

- 计数器按 abstractNum 共享；带 `w:startOverride` 的 num 独立计数，从覆盖值开始。
- 某层级计数时，更低层级按 `w:lvlRestart`（默认：任何更高层级计数时）归零重新开始，起始值取 `w:start`。
- 编号文字按 `w:lvlText` 把 `%1`–`%9` 替换为各层级当前值，每个层级按它自己的 `w:numFmt` 格式化；`w:isLgl` 时各层级一律写阿拉伯数字。
- 支持的格式：decimal、decimalZero、lowerLetter、upperLetter、lowerRoman、upperRoman、chineseCounting、chineseCountingThousand、ideographTraditional、decimalEnclosedCircle、bullet、none；其他格式按阿拉伯数字写出并记警告。
- 样式带编号而段落没写层级时，层级取编号定义中关联该样式（`w:pStyle`）的层级，没有则为 0。

## 表格

- 网格列数取 `w:tblGrid` 的列数，各行实际占到的列更多时取实际值。每行先跳过 `w:gridBefore` 列；单元格占 `w:gridSpan` 列；旧式 `w:hMerge` 继续格并入左侧格。
- `w:vMerge="restart"`（或不带值的首个 `w:vMerge`）开始纵向合并，其后同一起始网格列上的继续格并入，得到跨行数；继续格的文字不读。
- 没有单元格覆盖的网格位置记为缺失格。
- `w:tblHeader` 行的单元格记为列表头；表头仍按表头规则判定（`table-header.md`）。
- 单元格文字：格内各块按顺序用换行连接，带编号的段落带编号文字（项目符号写成 `-`），文本框内容跟在锚定段落后；嵌套表格逐行写成 `a | b | c`，作为外层单元格文字的一部分。
- **排版框**：网格只有 1 列的表格不作为表格，格内的块按正文规则读出（段落、标题、列表、格内的多列表格），地址仍为格内地址。
- 其余表格由解析器直接给出（来源 `parser_exact`），不做表格提取、选优与续表判定，从表头判定开始走表格结构、写法、检索文本环节。

## 解析结果

- `parse-native.json`（格式 `docx_reader_v1`）：读取模块的全部事实。
- 解析不缓存：每份文档读取不到 1 秒。
- 规则版本为 `docx_native.py` 的 `RULES_VERSION`，覆盖本文件全部规则。
