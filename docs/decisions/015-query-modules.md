# 015 查询侧各模块的归类与 V3.14 的最终配置

日期：2026-10-29　状态：待用户拍板

## 背景

V3.14 实现了查询侧的六个模块（提案 `docs/changes/v3.14.md`"模块"）：P3.1 分解，P3.2.1 改写、P3.2.2 翻译、P3.2.3 HyDE、P3.2.4 step-back 四种写法，P3.3 重排（搁置，未评估）。分解的合并方式（轮流取、全局 RRF、不合并）、写法的融合方式（RRF、不融合）与原问题一路都是配置项，共 120 种配置。按提案拍板问题 5，每个模块由助手给出类别与理由，用户拍板。

## 方法

- 判定：凑齐向量的支配关系（拍板问题 3），13 种组合 × 32 道可回答题；组合共用同一批题，组合数只表示一致程度，不作投票。
- 单因素对照：两侧只差一个因素，在另一因素的每种状态下各比一次（`reports/experiments/v3.14-layers/pairs.py`、`pairs.json`）。
- 扰动：推荐配置及其逐个去掉、加上一个模块的配置，在冻结的第 0 次生成与 3 次独立生成下各判定一次，4 次都相同为稳定（`reports/experiments/v3.14-perturbation/`）。独立生成的子问题与信息项对应由助手标注：96 题次中 49 题次的子问题与第 0 次不同，其中 5 题有结构变化（多余子问题增减、丢失或补回限定条件、一问多项），其余只是措辞不同。
- 审核页：`reports/experiments/v3.14-layers/index.html`；逐题结果：`reports/query/v3.14/index.html`。

## 结果与建议

"稳定"为 13 种组合 × 32 题中 4 次生成判定都相同的题次；"4 次"列为第 0–3 次生成的变好 / 变差题次。

| 模块 / 选项 | 建议类别 | 对照 | 4 次 | 稳定（变好 / 变差） |
|---|---|---|---|---|
| P3.2.2 翻译 | 固定启用（与 HyDE 一起 RRF 融合） | 推荐配置去掉翻译 → 推荐配置 | 105/53、85/60、84/34、75/44 | 38 / 9 |
| P3.2.3 HyDE | 固定启用（与翻译一起 RRF 融合） | 推荐配置去掉 HyDE → 推荐配置 | 120/59、125/51、118/55、88/73 | 50 / 16 |

### 理由

- **翻译、HyDE**：
  - 在推荐配置中各自的边际效果 4 次生成都是变好多于变差；单开时也是。
  - 单开翻译时，32 题中 15 题在全部组合中都变好、4 题都变差；单开 HyDE 时为 12 题、6 题。
  - 两组返回单元方向一致：整表组变好 77 / 变差 20，命中 chunk 组 72 / 26（推荐配置相对 V3.13，第 0 次）。
  - 按信息项数看，一项题变好 30 / 变差 0，两项题 56 / 40，三项及以上 63 / 6。
  - 按题型看，分解题、隐含前提、回答上的多跳题以变好为主；检索多跳题 2 / 4。
  - 检索范围内的文档语言与问题语言不同（32 题全部如此），译文与 HyDE 段落直接以文档语言匹配。
- **改写、step-back**：
  - 加到推荐配置上，4 次都是变差多于变好。
  - step-back 单开时只对两道隐含前提题有益，样本太少，不作为条件启用候选。
- **分解**：
  - 检索层稳定地有效：各信息项在对应子问题一路中的凑齐名次，在 20 种写法语境下都变好多于变差，4 次生成几乎相同。
  - 合成一个返回顺序后收益大多被抵消：轮流取把每个子问题的第 2、3 名推后，只有一个信息项的题被描述性子问题稀释。
  - 加分解的配置在验收第 1 条上第 0 次满足 13 / 13，其余 3 次为 8、10、10 / 13，不能复现。
  - 它适合作为 V3.15 的补救手段：只对一轮之后仍缺的信息项，用它对应的子问题单独检索，不与其他单元竞争位置。
- **合并方式**：第 0 次的 20 种语境中 16 种轮流取更好，但在推荐配置上 4 次生成方向不一。
- **原问题一路**：见决策 014。
- **融合方式**：
  - 翻译不融合（译文代替原句）的逐题判定最强：相对 V3.13 稳定变好 164、变差 55。
  - 但它丢掉了原句，K = 3 完整覆盖下降，验收第 1 条只有 2–3 / 13。
  - 推荐配置开两种写法，只能 RRF；它与翻译不融合相比，4 次生成方向不一（61/74、63/53、64/82、76/69）。
- **成本**（推荐配置，每题）：
  - 检索 3 次，约 0.73 秒（V3.13 为 1 次、约 0.23 秒）。
  - 规划 LLM 1 次（写法调用），约 7.9 秒、$0.0025。
  - 写法调用一次写出全部写法，包括不用的改写与 step-back。

## 推荐的最终配置

翻译 + HyDE，RRF 融合（原句 + 译文 + 各文档语言的 HyDE 段落），不分解，不重排。

- 相对 V3.13：4 次生成的变好 / 变差题次为 149/46、172/47、153/45、166/53，稳定的 132 / 22。
- 32 题中 14 题在全部组合中都变好，3 题都变差：CONTRACT-105-Q010、PO-25-15-Q002、PO-25-19-Q006。
- 最坏退化（验收 K 下由完整覆盖变为不完整，第 0 次）：PO-25-19-Q001、Q003、Q006、Q009，共 13 题次。
- 验收第 1 条：4 次生成分别有 11、11、11、12 / 13 种组合满足，不满足的是 RL-T、LL-T。这两种组合的 V3.13 在 K = 3 已有 25 题完整覆盖，推荐配置在 K = 3 多 0–1 题，其他三档多 1–2 题。
