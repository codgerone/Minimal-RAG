# 015 查询侧各模块的归类与 V3.14 的最终配置

日期：2026-11-02（重写；2026-10-29 的草稿依据写法提示词 v7、去编码未单独成开关，数字作废）　状态：已确定（2026-11-02 用户确认）

## 背景

V3.14 实现了查询侧的模块（提案 `docs/archive/changes/v3.14.md`"模块"）：
- P3.1 分解；
- P3.2.0 去编码；
- P3.2.1 改写、P3.2.2 翻译、P3.2.3 HyDE、P3.2.4 step-back 四种写法；
- P3.3 重排（搁置，未评估）。

分解的合并方式、写法的融合方式与原问题一路都是配置项，共 240 种配置。按提案拍板问题 5，每个模块由助手给出类别与理由，由用户拍板。各措施逐个讨论的结论已由用户确定（2026-10-29 至 11-02），本决策汇总这些结论及其数据。

## 方法

- **判定**：按凑齐向量的支配关系（拍板问题 3），在 13 种组合 × 32 道可回答题上判定。
- **单因素对照**：两侧只差一个因素。写法的单独效果用"去编码原句 → 去编码的该写法"；融合效果用"去编码原句 → 去编码原句 + 该写法 RRF"；叠加效果用"最终配置 → 最终配置 + 该写法"。
- **4 次生成**：冻结的第 0 次加 3 次独立生成。"逐组合"统计组合 × 题的题次；"逐题"统计题数：一题在一次生成中，变化的组合同向即取该方向，否则记为各有优势；4 次判定都相同记为稳定。13 种组合几乎总是同向，有效样本是 32 道题，因此以逐题为主。
- **数据**：
  - 对比页 `reports/query/v3.14/`；
  - 各措施的逐题原因 `reports/query/v3.14/analysis.html`，依据页 `reports/experiments/v3.14-factors/index.html`；
  - BM25 权重 `reports/experiments/v3.14-bm25-weight/`（决策 017）。

## 结论

V3.14 是对各措施检索效果的摸底，用来决定 V3.15 怎样使用它们；默认配置不变，与 V3.13 相同。

| 模块 | 在 V3.15 中的用法 | 理由 |
|---|---|---|
| P3.2.0 去编码 | 所有检索文本固定去编码 | 编码本身是噪声，即使恰好对某些表格题有利，也不应依靠它；数据上 8 题变好、7 题变差，方向不作为依据（决策 016） |
| P3.2.2 翻译 | 用于 LLM 规划出的新问题，按"原句 + 译文 RRF"；Q0 的第一轮不调用 LLM，不翻译 | 单独与融合都是 4 次生成变好多于变差，没有一题在 4 次中翻转；变差主要由 BM25 通道按关键词抬高无关单元造成（实验 B、F）。融合保留原句，退化较少 |
| 混合检索的 BM25 权重 | α = 1 不变 | 11 档 α 都不满足采纳规则（决策 017） |
| P3.2.3 HyDE | 兜底方式 | 单独用时 4 次生成之间方向不定（逐题稳定 4 / 4）；叠加在"原句 + 译文"上，逐组合偏正，但逐题稳定只有 3 / 2、3 题翻转，不能确认额外收益 |
| P3.2.1 改写 | 兜底方式，由 LLM 依据已读到的材料写 | 单独、融合、叠加都是逐题变差不少于变好；4 次生成几乎逐字相同，稳定不说明有真实作用 |
| P3.2.4 step-back | 兜底方式 | 单独用时变差明显多于变好，会丢掉关键限定条件；对答案写在统一规定中的题有益 |
| P3.1 分解 | 不预先分解；由 LLM 读材料后派生子问题 | 检索层逐组合偏正，但逐题以各有优势为主（稳定 3 / 3）；合并后收益被抵消 |
| 合并方式、原问题一路 | 不用：子问题各自返回，不合并，不另设原问题一路 | 合并层的损失是分解收益被抵消的主要原因；决策 014 随之关闭 |
| P3.3 重排 | 不加 | CPU 上每个子问题约 15 秒；材料总量成为问题时，再在兜底结果的合并处对照 |

## 参考：原句 + 译文 RRF（带去编码）相对 V3.13

这是 V3.14 中实测最好的单轮配置，只作为参考，不作为默认配置。

- **逐题**：32 题中 12 题 4 次生成都变好；5 题都变差：CONTRACT-105-Q009、PO-24-12-Q004、PO-25-15-Q001、PO-25-15-Q002、PO-25-19-Q006；没有一题在 4 次中翻转。
- **最坏退化**：验收 K 下由完整覆盖变为不完整的情况，4 次生成分别为 35、33、38、31 处（题 × 组合 × K）。
- **成本**（RM-T，每题，中位数 / 最大值）：检索 2 次，0.43 / 0.52 秒（V3.13 为 1 次，0.23 秒）；写法调用 1 次，7.4 / 40.1 秒。
- **验收**：提案原定的验收第 1 条是针对"最终配置"的。V3.14 改为摸底、默认配置不变后，这一条不再适用。按原条件，这一配置在 4 次生成中分别有 4、5、4、4 / 13 种组合满足：多数是增幅不够（-T 组合的 V3.13 在 K = 6–12 已有 27–29 / 32 题完整覆盖），少数是某档少 1 题（LL+-C、RM-C、LM-C）。

## 决定

2026-11-02 用户确定：
- V3.14 的默认配置不变，与 V3.13 相同；
- 各模块在 V3.15 中的用法见"结论"；
- 验收第 1 条不再适用；
- 决策 014 关闭。
