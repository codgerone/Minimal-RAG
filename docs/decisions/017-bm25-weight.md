# 017 混合检索的 BM25 权重

日期：2026-10-30　状态：实验中，待用户拍板

## 背景

混合检索按 RRF 等权融合向量排名与 BM25 排名（决策 009）。V3.14 的翻译让中文问题的 BM25 通道开始起作用，变差多数来自 BM25 只按关键词匹配、把含相同通用词而语义无关的单元抬前（提案 v3.14 实验 B、F）。用户提出下调 BM25 的权重。

## 方案

- 融合得分 = 1/(60 + 向量名次) + α/(60 + BM25 名次)，α ≥ 0 为 `[retriever] bm25_weight`，默认 1；查询设置，不进指纹。
- 检索缓存保存两个通道的名次，读出时按当前 α 重算融合得分与排序，换 α 不需要重新编码。
- 实验与采纳规则见提案 v3.14 问题 6。
