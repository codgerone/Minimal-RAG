# 011 跨页续表：按版面判定，与前表合并成一张表

日期：2026-10-16　状态：已采用（V3.11）

## 背景

Docling 按页识别表格，跨页的表格被拆成几张互不相关的表。后一页的部分没有表头，写不出列名，单元格只剩裸值（PO 25-19 第 3 页的数量表，roadmap 2.5）；它与前表也没有关联，后续"命中即返回整表"（P2.2）、"表格摘要"（P2.5）会漏掉它。

## 选项与决定

| 问题 | 选项 | 决定 |
|---|---|---|
| 续表怎么接入 | A. 只标记为前表的续表，借用前表表头，序列化和分块各做各的；B. 与前表合并成一张表，再做表头判定、文本化和分块 | **B**。合并后表头、列名、"整表"都自然成立，不需要额外的关联机制 |
| 位置怎么判定 | A. 两表之间只有页眉页脚；B. 先认出页眉页脚、推算正文区，再看表格到正文区边界的距离；C. 表格在页面上的相对位置，两表之间的文字只做辅助 | **C**。A 依赖 Docling 不误判页眉，也容不下"续表"字样；B 假设页眉页脚除数字外各页相同，长文档中页眉放节标题等情况会误判，且绕开了解析器已交付的结果 |
| 两表之间的文字 | 统计全部文字，或去掉 Docling 判出的页眉页脚 | 去掉 Docling 判出的页眉页脚，误判的部分由上限容纳；按宽度计数（全角 2、其他 1），使上限在中英文中对应相近的版面长度 |
| 表格上下边界的来源 | 胜出工具的外框，或 Docling 的表格位置 | Docling 的表格位置：每张表都有且只有一个，与哪个工具胜出无关；胜出工具的外框与它最多差 3 pt |
| 列几何 | A. 每列边界相差 ≤ 2 pt；B. 对应列区间重叠 ≥ 较窄一列的 50%；C. 外沿重叠 + 列分界的相对偏移 | **C**。A 只在两表都由画线工具胜出时成立；B 漏掉"窄表套在宽表内"和"外沿不动、内部分界移动"两种错位 |
| 后表重复印前表表头 | 处理或不处理 | 不处理：难以区分是续表还是新表 |

## 参数与依据

- **位置带**：页面上下各 20%（用户在 Word 中调试确定）。
- **两表之间文字宽度上限**：每侧 120（用户确定）。
- **列几何阈值**：外沿重叠 ≥ 0.8，列分界相对偏移 ≤ 0.35，可比分界不少于一半。
  - 素材：全部候选表（4 个工具 9 种策略）中列数相同的两两配对，378 对。
  - 同一张物理表（136 对，含续表的两页）：相对偏移最高 0.28，外沿重叠最低 0.86。未通过的 4 对是工具切错了列。
  - 不同的表：相对偏移中位数 1.40。通过的 66 对全是不同订单的同模板产品表，列边界只差几 pt；它们分属不同文档，由位置等条件排除。
  - 阈值只依据同一张物理表的测量偏差来定；同版式的不同表列宽本就可能不同，不作为依据。
- **列类型**：只用来否决。续表常有大片空格，全文字的表也没有稳定类型，要求有列支持会漏判。

规则细则：[rules/table-continuation.md](../rules/table-continuation.md)。实验：`reports/experiments/v3.11-continuation/`。

## 结果

- 本库 6 对相邻页表格中，只有 PO 25-19 p2 → p3 判为续表并合并；其余文档的 chunk 不变。
- 续表各行带上列名，ENSA 的 Item 4 行在 PO-25-19-Q003 的混合检索中进入前 3。

## 代价

- 合并后各行变长，表内分界移动：PO-25-19-Q002 的分组标题"ITEM 4 … HXE34K-S1"与 ELUC 行被切进相邻两块，structured 混合检索完整覆盖 18 → 17、纯向量命中 19 → 18。
  - 根因是 C2（分组标题不写进它所管的各行），留给 P2.2 / P2.3。
  - 接受依据是设计理由（续表应与前表是一张表），不是指标。
- 阈值只在 1 个正例上验证，没有校准；用户另找含跨页表格的 PDF 补充检查。
