# 003 证据按"信息项 → 方案 → excerpt"组织，映射按 excerpt 保存

日期：2026-10-07　状态：已采用（V3.3）

## 背景

数据集 2.1.0 中，一个证据组下的多段 excerpt 规定为"全部检索到才算覆盖"，但标注时混入了三种身份不同的原文：可互相替代的出处、缺一不可的组成部分、相关但不足以回答的段落。人工确认的映射实际上又对其中一部分按"任一即可"处理。标注与映射对同一结构的理解不一致，分块一变，自动判定就会按"全部"把不该要求的原文算进去。

另一类情况无法表达：一个信息项需要不相邻的几段原文共同得出（如订单总金额 = 单价表 × 各产品数量行），同时又存在单独一段就能得出的其他出处。

## 选项

| 选项 | 结论 |
|---|---|
| 保持"组内全部检索到"，把可替代出处删掉 | 不采用：丢掉了确实回答问题的原文，检索到它们不得分 |
| 改为"组内任一 excerpt 即可"，需要多段的拆成多个组 | 不采用：多段共同得出的信息项无法拆分，拆开后单段被误判为覆盖 |
| 按"哪些原文已经够用"定义证据组 | 不采用：组数取决于原文排版，同一问题换一份格式不同的文档，组数就变 |
| **信息项 = 证据组；组 = 任一方案；方案 = 全部 excerpt** | **采用** |

## 决定

1. 证据组先由问题和参考答案拆出信息项，再为每个信息项找原文；与信息项一一对应。
2. 一个证据组由一套或多套方案组成，满足任一套即覆盖；方案内的 excerpt 须全部检索到，且缺一不可。
3. 已确认映射按 excerpt 保存（excerpt → 可接受 chunk 组合），方案与证据组的组合由程序推出；同一段 excerpt 被多个证据组引用时只确认一次。
4. 映射记录 excerpt 原文哈希：原文改动后旧组合不再使用，改走自动判定。旧格式按"题号/组号"保存，改了原文仍会沿用错误的组合。

## 结果

数据集 3.0.0：24 道题、61 个证据组、73 套方案、57 段 excerpt，全部使用已确认映射。指标公式不变；与 2.1.0 的数字不直接比较。
